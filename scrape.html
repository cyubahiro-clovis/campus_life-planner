Scrape it

The scrape finds every element that matches the selector inside the board, then reads the title, date, length and tag from each one. The JSON uses the same shape as the planner's tasks, so you can import the file in the planner's settings.

Try .event, article:first or .event:has(.event-tag:contains(Study)).
